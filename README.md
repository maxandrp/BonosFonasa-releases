# Bonos FONASA — descargas

Activador en lote de bonos FONASA en el Portal Prestador MLE. Hecho por Maxand · Dr. Maximiliano Rodríguez Pavez.

Este repositorio contiene **solo las versiones publicadas** de Bonos FONASA, en la pestaña
[Releases](https://github.com/maxandrp/BonosFonasa-releases/releases). El código fuente es privado.

## Descargar

En la Release más reciente, bajar **BonosFonasa.exe**. No requiere instalación, pero el PC
debe estar configurado de antemano (navegador y acceso a la planilla).

## Actualizaciones

Bonos FONASA busca aquí una versión nueva cada vez que se abre. Si la hay, avisa y ofrece
instalarla. No envía ningún dato: solo lee la lista pública de versiones.
